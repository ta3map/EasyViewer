# Таблица GUI файлов проекта EasyViewer

## Файлы с "GUI" в названии

| Файл | Описание |
|------|----------|
| `signalViewerGUI.m` | Главное окно просмотра сигналов - основное окно для визуализации LFP данных, событий, стимулов, CSD, спайков |
| `signalAnalysisGUI.m` | Окно анализа сигналов - измерение параметров (slope, peak, onset, baseline), построение графиков, сохранение результатов |
| `fileManagerGUI.m` | Менеджер файлов с SQL базой данных - управление проектами, файлами, модулями, очередью обработки |
| `autoEventDetectionGUI.m` | Автоматическое обнаружение событий - настройка параметров детекции пиков в сигналах |
| `resultsGalleryGUI.m` | Галерея результатов анализа - просмотр и управление сохраненными результатами измерений |
| `plotFromTableGUI.m` | Построение боксплотов из таблиц - загрузка данных из MAT/Excel, фильтрация, визуализация |
| `measurementPropertiesGUI.m` | Свойства измерения - окно редактирования параметров конкретного измерения (открывается по двойному клику) |
| `editEventsGUI.m` | Редактирование событий - таблица для редактирования времени, комментариев, амплитуд, каналов событий |
| `editModuleParamsGUI.m` | Редактирование параметров модуля - GUI для изменения параметров модулей из JSON файлов |
| `optionsRemovalArtifactsGUI.m` | Удаление артефактов - настройка параметров удаления артефактов из сигналов |
| `convertAbf2zavGUI.m` | Конвертация ABF в ZAV - GUI для конвертации файлов формата ABF в формат ZAV |
| `convertNlx2zavGUI.m` | Конвертация Neuralynx в ZAV - GUI для конвертации файлов Neuralynx в формат ZAV |
| `editStimulusTimesGUI.m` | Редактирование времен стимулов - таблица для редактирования времен стимулов |
| `eventCrossCorrelationGUI.m` | Кросс-корреляция между событиями - анализ корреляции между двумя наборами событий |
| `chCossCorrelationGUI.m` | Кросс-корреляция между каналами - анализ корреляции между группами каналов |
| `convertOEP2zavGUI.m` | Конвертация OpenEphys в ZAV - GUI для конвертации файлов OpenEphys в формат ZAV |
| `ICAazGUI.m` | Fast ICA - графический интерфейс для независимого компонентного анализа |
| `PCAazGUI.m` | PCA - графический интерфейс для анализа главных компонент |
| `setupMeanEventsGUI.m` | Настройки усреднения событий - установка времени профиля для усреднения |
| `importEventsFromSimulusGUI.m` | Импорт событий из стимулов - создание событий на основе времен стимулов |
| `power_decay_GUI.m` | Inverse Log GUI - тестовый GUI с слайдером для обратного логарифма |
| `spectralDensityGUI.m` | Спектральная плотность - построение графиков спектральной плотности мощности |
| `setupSignalFilteringGUI.m` | Настройка фильтрации сигнала - выбор каналов и параметров фильтрации (highpass, bandpass, lowpass) |
| `lineStyleGUI.m` | Стиль линий - настройка стилей отображения линий на графиках |
| `ZScoreGUI.m` | Z-Score - построение Z-score графиков для выбранных каналов |

## Файлы без "GUI" в названии, но создающие GUI фигуры

| Файл | Описание |
|------|----------|
| `app.m` | Главное окно приложения - стартовое окно с кнопками запуска Signal Viewer и Signal Analysis |
| `importLFP.m` | Импорт LFP данных - GUI для импорта данных из ZAV файлов с выбором каналов и режимов |
| `performChannelOperations.m` | Операции с каналами - GUI для выполнения математических операций между группами каналов (A+B, A-B, A*B, A/B) |
| `SubMeanFigSettings.m` | Настройки вычитания среднего - выбор каналов для вычитания среднего значения |
| `CSDfigSettings.m` | Настройки отображения CSD - выбор каналов для CSD и настройка коэффициента контраста |
| `addEventSettingsUicontrol.m` | Настройки ручного создания событий - параметры для ручного добавления событий (режим, канал, амплитуда и т.д.) |
| `calculateAndPlotMeanEvents.m` | Построение усредненных событий - создает фигуру с графиками усредненных событий (Tag: 'meanSignalResult') |
| `plotClusterPermutationResults.m` | Результаты кластерного пермутационного теста - создает фигуру с результатами статистического теста |
| `dataComparerApp.m` | Сравнение данных - GUI для загрузки и сравнения двух наборов данных, объединения результатов |
