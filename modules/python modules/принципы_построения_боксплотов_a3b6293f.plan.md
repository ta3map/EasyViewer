# Принципы построения боксплотов

## Основные компоненты

### 1. Загрузка данных

- Чтение Excel файла в таблицу данных
- Поддержка всех колонок из файла

### 2. Парсинг фильтров групп

Формат фильтров: `A:key>=value,key<=value,key=value;B:key2>=value2`

- Группы разделяются `;` или переносом строки
- Условия внутри группы разделяются `,`
- Буквы A, B, C... привязывают фильтры к группам
- Операторы: `>=`, `<=`, `>`, `<`, `=`, `!=`
- Поддержка пустых значений: `key=`, `key=null`, `key=nan`, `key=empty`

### 3. Создание групп

- Применение фильтров к данным
- Создание колонки `group_label` с метками групп
- Маппинг букв (A, B, C...) на кастомные подписи
- Диагностика фильтрации (вывод количества строк для каждой группы)

### 4. Парсинг параметров

- Список колонок для анализа (каждая на новой строке)
- Нормализация переносов строк (`\r\n`, `\r` → `\n`)

### 5. Расчет статистики

Для каждого параметра и каждой группы:

- mean, std, median, q25, q75, count

### 6. Статистические тесты

- Попарные t-test между всеми группами для каждого параметра
- Сохранение: statistic, pvalue, n1, n2, group1, group2
- Сортировка групп по буквам (A, B, C...) для упорядочивания

### 7. Парсинг цветов

Формат: `A:#FF0000,B:#00FF00` или построчно

- Маппинг на группы через буквы или прямые подписи

### 8. Визуализация

- Subplot сетка: `ceil(n_params / 2)` строк × 2 колонки
- Для каждого параметра отдельный подграфик
- Боксплоты для каждой группы с:
- Отображением всех точек (`boxpoints='all'`)
- Jitter для точек
- Аннотацией `n=X` на медиане
- Оси X: подписи групп (сортировка по буквам)
- Оси Y: название параметра, диапазон зависит от `y_axis_range`:
- `auto`: автоматически
- `minmax`: min/max всех данных
- `percentile`: перцентили 0.05 и 0.95

### 9. Скобки значимости

- Горизонтальные линии между группами
- Вертикальные "стенки" на концах
- Текст с p-value и звездочками (`***` p<0.001, `**` p<0.01, `*` p<0.05, `ns` иначе)
- Многоуровневое расположение (если скобки пересекаются)
- Показывать все p-values или только значимые (p < 0.05) в зависимости от `show_all_pvalues`
- Позиционирование скобок выше максимального значения данных с отступами

### 10. Параметры конфигурации

- `excel_path`: путь к Excel файлу
- `group_filters`: строки фильтров
- `analysis_columns`: список колонок для анализа
- `show_statistics`: включить/выключить статистику
- `show_all_pvalues`: показывать все или только значимые
- `y_axis_range`: способ определения границ Y-оси
- `group_labels`: кастомные подписи (A:Подпись1,B:Подпись2)
- `group_colors`: цвета в HEX (A:#FF0000,B:#00FF00)
- `title`: заголовок графика

## Последовательность выполнения

1. Загрузка Excel → таблица данных
2. Парсинг `group_filters` → список условий для каждой группы
3. Парсинг `group_labels` → словарь буква→подпись
4. Применение фильтров → создание `group_label` колонки
5. Парсинг `analysis_columns` → список параметров
6. Расчет статистики по группам
7. Статистические тесты (если `show_statistics=true`)
8. Парсинг `group_colors` → словарь группа→цвет
9. Построение визуализации с боксплотами и скобками значимости
