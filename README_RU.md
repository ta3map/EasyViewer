## Введение

Easy Viewer предназначен для визуализации и анализа многоканальных электрофизиологических сигналов (LFP). Программа поддерживает работу с различными форматами данных, предоставляет инструменты для обработки сигналов, обнаружения событий, измерения параметров и автоматизации анализа.

![Главное окно приложения](assets/splash.png)

## Начало работы

### Запуск приложения

Запустите приложение, выполнив команду `app()` в командном окне MATLAB. Откроется главное окно с двумя основными режимами работы:

- **Signal Viewer** - режим просмотра сигналов
- **Signal Analysis** - режим анализа и измерения параметров

![Главное окно приложения](docs/screenshots/placeholder_app_main.png)

### Выбор режима работы

Нажмите кнопку **Signal Viewer** для открытия окна просмотра сигналов или **Signal Analysis** для открытия окна анализа. Оба режима могут работать независимо, но при открытии одного окна другое автоматически закрывается.

Кнопка **⚙** открывает глобальные настройки приложения.

## Основные компоненты

### Signal Viewer

Окно просмотра сигналов предназначено для визуализации многоканальных LFP сигналов, управления событиями и стимулами, обработки сигналов и базового анализа.

Основные возможности:
- Загрузка файлов в форматах ZAV (.mat) и EV (.ev)
- Просмотр многоканальных сигналов с настройкой отображения
- Управление событиями (ручное добавление, автоматическое обнаружение)
- Управление стимулами
- Обработка сигналов (фильтрация, вычитание среднего, CSD)
- Инструменты анализа (Z-score, спектральная плотность, PCA, корреляция)

Подробное описание: [Signal Viewer](docs/signal_viewer_rus.md)

### Signal Analysis

Окно анализа предназначено для измерения параметров сигнала относительно стимулов или событий.

Основные возможности:
- Измерение параметров (slope, peak, onset, baseline)
- Работа с таблицей измерений
- Сглаживание сигнала
- Сохранение результатов в Excel
- Hot Resave для автоматического пересохранения
- Просмотр среднего трейса по измерениям

Подробное описание: [Signal Analysis](docs/signal_analysis_rus.md)

### File Manager

Файловый менеджер с поддержкой SQL базы данных для организации проектов, групп файлов и метаданных.

Основные возможности:
- Создание и управление проектами
- Группировка файлов
- Хранение метаданных
- Запуск модулей автоматизации
- Просмотр результатов анализа

Подробное описание: [File Manager](docs/file_manager_rus.md)
