# План выноса функций построения графиков

## Анализ текущей структуры

В файле `plotFromTableGUI.m` находятся три функции построения графиков с одинаковой сигнатурой `(fig, state)`:

1. **createCorrelationFigure** (строки 2245-2648, ~404 строки) - построение корреляционных графиков
2. **createHistogramFigure** (строки 2650-2912, ~263 строки) - построение гистограмм  
3. **createBoxplotFigure** (строки 2914-3282, ~369 строк) - построение боксплотов

Также есть две вспомогательные функции, используемые всеми тремя функциями:

- **plotFileIdsOnAxes** (строки 3284-3343) - отображение File IDs рядом с точками
- **plotYValuesOnAxes** (строки 3345-3410) - отображение Y значений рядом с точками

Функции вызываются в строках 1737, 1739, 1741 в зависимости от `state.plotMode`.

## Зависимости

Все функции используют внешние функции из папки `functions/`:

- `boxplotParseGroupFilters`
- `boxplotApplyGroupFilters`
- `boxplotCalculateMaxBracketLevelForParams`
- `boxplotAddSignificanceBracketsForParams`
- `debugState`

Эти функции уже находятся в отдельных файлах и доступны через путь поиска MATLAB.

## План действий

### 1. Создать файлы для функций построения графиков

Создать три новых файла в папке `functions/GUIfunctions/`:

- `createCorrelationFigure.m` - функция построения корреляционных графиков
- `createHistogramFigure.m` - функция построения гистограмм
- `createBoxplotFigure.m` - функция построения боксплотов

Каждый файл будет содержать соответствующую функцию с полным кодом из исходного файла.

### 2. Создать файлы для вспомогательных функций

Создать два файла для вспомогательных функций в папке `functions/GUIfunctions/`:

- `plotFileIdsOnAxes.m` - отображение File IDs
- `plotYValuesOnAxes.m` - отображение Y значений

### 3. Обновить основной файл

В `plotFromTableGUI.m`:

- Удалить определения функций `createCorrelationFigure`, `createHistogramFigure`, `createBoxplotFigure`
- Удалить определения функций `plotFileIdsOnAxes` и `plotYValuesOnAxes`
- Оставить вызовы функций без изменений (строки 1737, 1739, 1741), так как MATLAB найдет функции в отдельных файлах

### 4. Проверка сигнатур

Все функции будут иметь одинаковую сигнатуру:

- `createCorrelationFigure(fig, state)`
- `createHistogramFigure(fig, state)`
- `createBoxplotFigure(fig, state)`

Вспомогательные функции сохранят свои текущие сигнатуры:

- `plotFileIdsOnAxes(ax, xPositions, yPositions, fileIds, xOffset, yOffset, useAbsoluteOffset)`
- `plotYValuesOnAxes(ax, xPositions, yPositions, yValues, xOffset, yOffset, formatStr, useAbsoluteOffset)`
