# Модули автоматизации

Модули автоматизации позволяют выполнять анализ данных для множества файлов без ручного вмешательства.

## Доступные модули

### autoClusterPermutationTest

Кластерный пермутационный тест для статистического анализа временных рядов.

**Параметры визуализации:**
- **xLimits** - временное окно анализа в миллисекундах [до стимула, после стимула]
- **removeBaseline** - удалять ли среднее значение baseline
- **removeArtifact** - удалять ли артефакт стимула
- **artifactWindow_ms** - длительность окна артефакта в миллисекундах
- **showBaselinePeriod** - показывать ли baseline период на графике
- **showMeanSignal** - показывать ли средний сигнал

**Параметры теста:**
- **numPermutations** - количество пермутаций (рекомендуется 1000-10000)
- **clusterThreshold** - уровень значимости для порога t-статистики (обычно 0.05)
- **minClusterSize_ms** - минимальный размер кластера в миллисекундах
- **startTrial** / **endTrial** - диапазон триалов для анализа (пусто для всех)
- **removeEdgeTrials** - удалять ли триалы на краях

**Выходные данные:**
- График с t-статистикой и значимыми кластерами
- Файл .meta с результатами анализа

Подробное описание метода: [Кластерный пермутационный тест](cluster_permutation_test_rus.md)

![Результат кластерного теста](screenshots/module_cluster_test.png)

### autoMeanStimulus

Усреднение сигнала по стимулам с автоматическим обнаружением пиков.

**Параметры визуализации:**
- **autoScale** - автоматическое масштабирование
- **xLimits** - временное окно в миллисекундах
- **showOriginalTraces** - показывать исходные трейсы
- **removeBaseline** - удалять baseline
- **removeArtifact** - удалять артефакт
- **artifactWindow_ms** - размер окна артефакта

**Параметры детекции:**
- **Polarity** - полярность пиков (positive/negative)
- **MinPeakProminence** - минимальная выраженность пика
- **MinPeakDistance_s** - минимальное расстояние между пиками
- **MaxPeakWidth_s** - максимальная ширина пика
- **SmoothingKernel_s** - размер ядра сглаживания
- **UseOriginalData** - использовать исходные данные для детекции

**Выходные данные:**
- График усредненного сигнала с обнаруженными пиками
- Таблица с результатами детекции
- Файл изображения (PNG или FIG)

![Результат усреднения по стимулам](screenshots/module_mean_stimulus.png)

### autoDetectStimuli

Автоматическое обнаружение стимулов в сигнале.

**Параметры детекции:**
- **Polarity** - полярность стимулов (positive/negative)
- **MinPeakProminence** - минимальная выраженность пика
- **MinPeakDistance_s** - минимальное расстояние между стимулами
- **MaxPeakWidth_s** - максимальная ширина стимула
- **SmoothingKernel_s** - размер ядра сглаживания
- **Channel** - номер канала для детекции

**Выходные данные:**
- Временные метки обнаруженных стимулов
- Сохранение стимулов в файл настроек

![Результат обнаружения стимулов](screenshots/module_detect_stimuli.png)

### autoSlopeMeasurement

Автоматическое измерение slope для всех стимулов.

**Параметры измерения:**
- **Channel** - номер канала
- **BaselineStart_s** - начало baseline диапазона (относительно стимула)
- **BaselineEnd_s** - конец baseline диапазона
- **PeakStart_s** - начало peak диапазона
- **PeakEnd_s** - конец peak диапазона
- **SlopePercent** - процент для расчета slope
- **PeakPolarity** - полярность пика (positive/negative)

**Параметры временного окна:**
- **TimeBack_s** - время до стимула
- **TimeForward_s** - время после стимула

**Параметры обработки:**
- **SmoothingEnabled** - включить сглаживание
- **SmoothingSpan** - размер ядра сглаживания
- **SmoothingMethod** - метод сглаживания (moving/median)
- **RemoveArtifact** - удалять артефакт
- **ArtifactWindow_ms** - размер окна артефакта

**Выходные данные:**
- Excel файл с результатами измерений для всех стимулов
- Метаданные измерений

![Результат измерения slope](screenshots/module_slope_measurement.png)

## Использование модулей

### Настройка параметров

1. Откройте File Manager
2. Выберите модуль из выпадающего списка **Module**
3. Нажмите кнопку **Edit Module Params**
4. Настройте параметры в открывшемся окне
5. Сохраните параметры

![Настройка параметров модуля](screenshots/module_edit_params.png)

### Запуск модуля

1. Выберите файлы в списке File Manager
2. Выберите модуль
3. Нажмите кнопку **Launch Module**
4. Дождитесь завершения обработки

### Очередь модулей

Модули могут быть добавлены в очередь для последовательного выполнения:

1. Настройте параметры модуля
2. Нажмите кнопку **Add to queue**
3. Повторите для других модулей
4. Нажмите кнопку **Launch Module** для выполнения всей очереди

![Очередь модулей](screenshots/module_queue.png)

### Просмотр результатов

Результаты анализа сохраняются в базу данных File Manager. Для просмотра:

1. Выберите файл в списке
2. Результаты отображаются в таблице **Results**
3. Выберите результат и нажмите **Open Result** для просмотра

![Просмотр результатов модуля](screenshots/module_results.png)

## Формат параметров

Параметры модулей хранятся в JSON формате. Файлы конфигурации находятся в папке `modules/`:

- `autoClusterPermutationTest.json`
- `autoMeanStimulus.json`
- `autoDetectStimuli.json`
- `autoSlopeMeasurement.json`

## Результаты анализа

Результаты сохраняются в базу данных File Manager в таблице `analysis_results`:

- **module_name** - название модуля
- **module_display_name** - отображаемое название
- **module_description** - описание модуля
- **analysis_timestamp** - временная метка анализа
- **report_path** - путь к файлу отчета
- **parameters_json** - JSON с параметрами анализа

Файлы отчетов (графики, таблицы) сохраняются в папке с исходными данными.
