# Инструменты анализа

Программа предоставляет различные инструменты для анализа электрофизиологических сигналов.

## Z-score

Z-score нормализация преобразует сигнал к стандартному нормальному распределению.

**Открытие:** Меню **Analysis/Z-score** в Signal Viewer

**Параметры:**

- Выбор каналов для нормализации
- Метод расчета (по всему сигналу или по окну)

![Z-score нормализация](screenshots/zscore.png)

## Spectral Density

Спектральная плотность мощности показывает распределение мощности сигнала по частотам.

**Открытие:** Меню **Analysis/Spectral Density** в Signal Viewer

**Параметры:**

- Выбор каналов для анализа
- Метод расчета (FFT, Welch и др.)
- Размер окна
- Перекрытие окон

**Выходные данные:**

- График спектральной плотности
- Таблица с результатами

![Спектральная плотность](screenshots/spectral_density.png)

## Cross-Correlation

Кросс-корреляция показывает взаимосвязь между событиями или каналами.

**Открытие:** Меню **Analysis/Cross-Correlation** в Signal Viewer

### Кросс-корреляция событий

Анализ временных взаимосвязей между событиями.

**Параметры:**

- Выбор событий для анализа
- Временное окно корреляции
- Метод нормализации

![Кросс-корреляция событий](screenshots/event_crosscorrelation.png)

### Кросс-корреляция каналов

Анализ взаимосвязей между каналами.

**Параметры:**

- Выбор каналов для анализа
- Временное окно корреляции
- Метод нормализации

![Кросс-корреляция каналов](screenshots/channel_crosscorrelation.png)

## PCA (Principal Component Analysis)

Анализ главных компонент выявляет основные паттерны в многоканальных данных.

**Открытие:** Меню **Analysis/PCA** в Signal Viewer

**Параметры:**

- Выбор каналов для анализа
- Количество главных компонент
- Метод нормализации данных

**Выходные данные:**

- График главных компонент
- Таблица с коэффициентами
- График объясненной дисперсии

![PCA анализ](screenshots/pca.png)

## Data Operations

Операции с данными каналов позволяют выполнять математические операции между каналами.

**Открытие:** Меню **Analysis/Data Operations** в Signal Viewer

**Доступные операции:**

- Сложение каналов
- Вычитание каналов
- Умножение каналов
- Деление каналов
- Усреднение каналов

**Параметры:**

- Выбор каналов для операции
- Тип операции
- Сохранение результата как нового канала

![Операции с данными](screenshots/data_operations.png)

## Compare Average Data

Сравнение усредненных данных позволяет сравнивать средние трейсы между различными условиями.

**Открытие:** Меню **Analysis/Compare average data** в Signal Viewer

**Параметры:**

- Выбор двух наборов данных для сравнения
- Временное окно сравнения
- Метод статистического сравнения

**Выходные данные:**

- График с наложенными средними трейсами
- Статистические показатели различий

![Сравнение средних данных](screenshots/compare_average.png)

## Boxplot from Table

Построение боксплотов из таблицы результатов измерений.

**Открытие:** Меню **Analysis/Boxplot from Table** в Signal Viewer

**Параметры:**

- Выбор Excel файла с данными
- Выбор колонок для построения боксплотов
- Группировка данных
- Настройки визуализации

**Выходные данные:**

- График с боксплотами
- Статистические показатели

Подробное описание: [Boxplot from Table](boxplotFromTableGUI_eng.md)

![Боксплоты из таблицы](screenshots/boxplot_table.png)

## Применение инструментов анализа

### Выбор данных

Большинство инструментов требуют предварительной загрузки данных в Signal Viewer или Signal Analysis.

### Настройка параметров

Каждый инструмент имеет собственное окно настроек с параметрами, специфичными для метода анализа.

### Сохранение результатов

Результаты анализа могут быть сохранены:

- Как графики (PNG, FIG)
- Как таблицы (Excel)
- Как данные (MAT)

### Интеграция с File Manager

Результаты анализа могут быть сохранены в базу данных File Manager для последующего просмотра и сравнения.
