# Конвертация данных

Программа поддерживает конвертацию данных из различных форматов в формат ZAV (.mat).

## Доступные форматы

### Neuralynx (NLX) to ZAV

Конвертация файлов Neuralynx (.nlx) в формат ZAV.

**Открытие:** Меню **File/Import** → выберите **NLX** или **File/convert NLX to ZAV**

**Параметры конвертации:**

- **Select Record Path** - выбор папки с файлами Neuralynx
- **Detect MUA** - включить обнаружение мультиюнитной активности
- **threshold (n*STD)** - порог детекции MUA в единицах стандартного отклонения
- **all channels** / **specific channels** - выбор каналов для конвертации
- **Fs, Hz** - частота дискретизации выходных данных (по умолчанию 1000 Гц)
- **Resample** - выполнять ли ресемплинг данных

**Процесс:** Нажмите **Start Conversion** для начала конвертации. Прогресс отображается в окне.

![Конвертация NLX to ZAV](screenshots/convert_nlx.png)

### ABF to ZAV

Конвертация файлов Axon Binary Format (.abf) в формат ZAV.

**Открытие:** Меню **File/Import** → выберите **ABF**

**Параметры конвертации:**

- **Select ABF File** - выбор файла .abf
- **Select Channels** - выбор каналов для конвертации
- **Fs, Hz** - частота дискретизации выходных данных
- **Resample** - выполнять ли ресемплинг данных

![Конвертация ABF to ZAV](screenshots/convert_abf.png)

### Open Ephys to ZAV

Конвертация файлов Open Ephys в формат ZAV.

**Открытие:** Меню **File/Import** → выберите **Open Ephys**

**Параметры конвертации:**

- **Select Record Path** - выбор папки с файлами Open Ephys
- **Select Channels** - выбор каналов для конвертации
- **Fs, Hz** - частота дискретизации выходных данных
- **Resample** - выполнять ли ресемплинг данных

![Конвертация Open Ephys to ZAV](screenshots/convert_oep.png)

### Импорт LFP

Импорт LFP данных из других форматов или прямого ввода.

**Открытие:** Меню **File/Import** → выберите **ZAV (.mat)**

**Параметры импорта:**

- Выбор файла с данными
- Настройка параметров сигнала (частота дискретизации, каналы)

![Импорт LFP](screenshots/import_lfp.png)

## Формат ZAV

ZAV формат представляет собой .mat файл MATLAB со следующей структурой:

- **lfp** - массив данных сигнала [время × каналы × свипы]
- **time** - вектор времени
- **Fs** - частота дискретизации
- **hd** - заголовок с метаданными
- **channelNames** - названия каналов
- Дополнительные поля в зависимости от типа данных

Подробное описание формата: [ZAV Format](Zav_mat_format_rus.md)

## Настройки конвертации

### Частота дискретизации

Поле **Fs, Hz** определяет частоту дискретизации выходных данных. Если исходная частота отличается, выполняется ресемплинг.

### Ресемплинг

Чекбокс **Resample** включает ресемплинг данных к указанной частоте дискретизации. Если выключен, данные сохраняются с исходной частотой.

### Выбор каналов

Для всех форматов доступен выбор конкретных каналов или конвертация всех каналов.

### Обнаружение MUA

Для формата NLX доступно обнаружение мультиюнитной активности во время конвертации:

- **Detect MUA** - включить детекцию
- **threshold (n*STD)** - порог в единицах стандартного отклонения

## Сохранение результатов

Результаты конвертации сохраняются в .mat файлы в формате ZAV. Файлы могут быть сразу открыты в Signal Viewer или Signal Analysis.

## Обработка ошибок

При ошибках конвертации в окне отображается сообщение об ошибке. Проверьте:

- Корректность формата исходных файлов
- Доступность всех необходимых файлов
- Достаточность места на диске
- Корректность параметров конвертации
