# Измерения параметров

Signal Analysis предоставляет инструменты для измерения различных параметров сигнала относительно стимулов или событий.

## Параметры измерения

### Slope

Slope (крутизна) измеряет скорость изменения сигнала в определенном диапазоне относительно пика.

**Расчет:**

1. Определяется пик в заданном диапазоне (peak range)
2. Вычисляется процент от амплитуды пика (Slope Percent)
3. Находится точка на подъеме/спаде сигнала, соответствующая этому проценту
4. Вычисляется линейная регрессия между точкой процента и пиком
5. Slope - это угловой коэффициент регрессии

**Параметры:**

- **Slope Percent** - процент от амплитуды пика для расчета (0-100)
- **Peak Range** - диапазон поиска пика (Peak Start, Peak End)
- **Polarity** - полярность пика (positive/negative)

![Измерение slope](images/placeholder_measurement_slope.png)

### Peak

Peak (пик) - максимальное или минимальное значение сигнала в заданном диапазоне.

**Расчет:**

1. В диапазоне Peak Range находится экстремум (максимум для positive, минимум для negative)
2. Записывается время и значение пика

**Параметры:**

- **Peak Range** - диапазон поиска пика
- **Polarity** - полярность пика

![Измерение peak](images/placeholder_measurement_peak.png)

### Onset

Onset (начало) - момент начала изменения сигнала.

**Методы расчета:**

- **Derivative** - на основе производной сигнала
- **Threshold** - на основе порога в единицах стандартного отклонения

**Параметры:**

- **Onset Method** - метод расчета (derivative/threshold)
- **Onset Threshold** - порог для метода threshold (в единицах std)

![Измерение onset](images/placeholder_measurement_onset.png)

### Baseline

Baseline (базовая линия) - среднее значение сигнала в заданном диапазоне до стимула.

**Расчет:**

1. В диапазоне Baseline Range вычисляется среднее значение сигнала
2. Это значение используется как опорная точка для других измерений

**Параметры:**

- **Baseline Range** - диапазон для расчета (Baseline Start, Baseline End)

![Измерение baseline](images/placeholder_measurement_baseline.png)

## Настройка измерений

### Выбор канала

Выпадающий список **Channel** позволяет выбрать канал для измерения. При изменении канала все измерения пересчитываются.

### Полярность пика

Выпадающий список **Polarity** определяет направление поиска пика:

- **Positive** - поиск положительного пика (максимума)
- **Negative** - поиск отрицательного пика (минимума)

### Диапазоны измерения

Все диапазоны задаются относительно текущей точки отсчета (стимул, событие или время):

- **Baseline Start/End** - диапазон для расчета baseline
- **Peak Start/End** - диапазон для поиска пика

Значения вводятся в выбранных единицах времени (s, ms, min).

Кнопка **★** рядом с полем позволяет выбрать точку на графике кликом мыши.

### Процент для slope

Поле **Slope Percent** задает процент от амплитуды пика, используемый для расчета slope. Значение от 0 до 100.

## Визуализация измерений

### Отображение элементов

Чекбоксы управляют видимостью элементов на графике:

- **Baseline** - отображение диапазона baseline и его значения
- **Peak** - отображение диапазона peak, маркера пика и его значения
- **Slope** - отображение линии регрессии slope
- **Onset** - отображение маркера онсета и его времени

### Таблица текущих результатов

Таблица показывает результаты для текущего измерения:

- **Slope** - значение slope
- **Peak Time (rel)** - время пика относительно точки отсчета
- **Peak Amplitude** - амплитуда пика
- **Onset Time (rel)** - время онсета относительно точки отсчета
- **Baseline** - значение baseline

## Автоматическое измерение

Кнопка **Auto Measure All** автоматически измеряет параметры для всех стимулов/событий/свипов:

1. Переходит к каждому стимулу/событию/свипу
2. Выполняет измерение с текущими настройками
3. Добавляет результат в таблицу результатов

## Таблица результатов

Результаты измерений накапливаются в таблице результатов. Каждая строка содержит:

- **Stimulus** - номер стимула/события/свипа
- **Slope** - значение slope
- **Peak Time (rel/abs)** - время пика (относительное и абсолютное)
- **Peak Amplitude** - амплитуда пика
- **Peak Value (rel)** - значение пика относительно baseline
- **Onset Time (rel/abs)** - время онсета (относительное и абсолютное)
- **Peak - Onset** - разница между пиком и онсетом
- **Baseline** - значение baseline
- **Channel** - номер канала
- **Stim Time** - время стимула/события
- **Info** - дополнительная информация

## Таблица средних значений

Таблица показывает средние значения по всем измерениям в таблице результатов:

- **Slope** - среднее значение slope
- **Peak Time (rel)** - среднее время пика
- **Peak Amplitude** - средняя амплитуда пика
- **Onset Time (rel)** - среднее время онсета
- **Baseline** - среднее значение baseline
- **Peak - Onset** - средняя разница между пиком и онсетом

## Средний трейс

Кнопка **Av. Trace** переключает режим отображения среднего сигнала по всем измерениям. В этом режиме:

- График показывает усредненный сигнал
- Измерения выполняются относительно среднего сигнала
- Это позволяет оценить типичный ответ и его вариабельность

## Сглаживание перед измерением

Сглаживание сигнала может быть включено для уменьшения влияния шума на измерения:

- **Enable** - включить сглаживание
- **Kernel** - размер ядра сглаживания
- **Method** - метод сглаживания (Moving/Median)
- **Show Raw** - показывать исходный сигнал

Сглаживание применяется перед всеми расчетами измерений.

## Метаданные измерений

Каждое измерение сохраняет метаданные:

- Параметры настройки измерения
- Временные метки диапазонов
- Метод расчета
- Информация о канале и стимуле

Метаданные доступны через кнопку **Collect All** и сохраняются при экспорте результатов.

## Сохранение результатов

Результаты измерений могут быть сохранены:

- В Excel файл (кнопка **Save** или **Save As**)
- С метаданными (через **Collect All**)
- С автоматическим пересохранением (Hot Resave)

## Навигация при измерениях

При измерении параметров доступна навигация:

- Кнопки **Previous** и **Next** перемещают к предыдущему/следующему стимулу/событию
- Режим навигации определяется автоматически на основе загруженных данных
- Статусная строка показывает текущий режим навигации
