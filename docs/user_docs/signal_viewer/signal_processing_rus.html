Обработка сигналов

Программа предоставляет различные методы обработки сигналов для улучшения качества данных и выделения интересующих компонентов.

Фильтрация

Фильтрация сигнала позволяет выделить частотные компоненты интереса.

Открытие: Меню Options/Filtering в Signal Viewer

Выбор каналов

Левая панель содержит список всех каналов с чекбоксами. Выберите каналы, к которым будет применена фильтрация.

Кнопки Select ALL и Deselect ALL управляют выбором всех каналов.

Типы фильтров

Выпадающий список Filter Type позволяет выбрать тип фильтра:

  • bandpass - полосовой фильтр (пропускает частоты в заданном диапазоне)
  • lowpass - низкочастотный фильтр (пропускает частоты ниже заданной)
  • highpass - высокочастотный фильтр (пропускает частоты выше заданной)

Параметры фильтра

  • Lower Frequency - нижняя граница частоты (Гц)
  • Upper Frequency - верхняя граница частоты (Гц)
  • Filter Order - порядок фильтра (определяет крутизну склона)

Предпросмотр

Кнопка Check Filtration показывает частотную характеристику фильтра на графике в нижней части окна. Это позволяет оценить эффект фильтрации перед применением.

Применение

Кнопка Apply применяет фильтрацию к выбранным каналам. Кнопка Cancel отменяет изменения.

Вычитание среднего

Вычитание среднего значения помогает устранить общий для всех каналов фоновый шум.

Открытие: Меню Options/Average subtraction в Signal Viewer

Выбор каналов

Левая панель содержит список каналов с чекбоксами. Выберите каналы, которые будут участвовать в расчете среднего значения.

Среднее значение вычисляется по всем выбранным каналам и вычитается из каждого канала.

Кнопки Select ALL и Deselect ALL управляют выбором каналов.

Применение

Кнопка Apply применяет вычитание среднего к выбранным каналам.

CSD (Current Source Density)

CSD визуализирует пространственное распределение источников и стоков тока.

Открытие: Меню View/CSD displaying или чекбокс CSD на панели инструментов в Signal Viewer

Выбор каналов

Левая панель содержит список каналов с чекбоксами. Выберите каналы, которые будут участвовать в расчете CSD.

Кнопки Select ALL и Deselect ALL управляют выбором каналов.

Параметры визуализации

  • Contrast Coef. - коэффициент контрастности отображения (улучшает различимость областей)
  • Smooth Coef. - коэффициент сглаживания (уменьшает шум)

Применение

Кнопка Apply применяет настройки CSD к выбранным каналам и обновляет визуализацию.

Удаление артефактов

Удаление артефактов исключает короткий период сразу после стимула из отображения.

Открытие: Меню Options/Removal of Artifacts в Signal Viewer или Signal Analysis

Параметры

  • Artifact Window (ms) - размер временного окна после стимула, которое исключается из отображения

Применение

Настройки применяются автоматически при изменении параметра.

Сглаживание

Сглаживание сигнала уменьшает высокочастотный шум.

Доступно в: Signal Analysis

Включение сглаживания

Чекбокс Enable включает или выключает сглаживание сигнала.

Параметры сглаживания

  • Kernel - размер ядра сглаживания (количество точек)
  • Method:
    • Moving - скользящее среднее
    • Median - медианный фильтр
  • Show Raw - отображение исходного сигнала вместе со сглаженным

Настройки каналов для обработки

В таблице каналов на боковой панели Signal Viewer можно управлять применением обработки к каждому каналу:

  • Filter - применение фильтрации
  • Averaging - участие в усреднении для вычитания среднего
  • CSD - участие в расчете CSD
  • Baseline - вычитание базовой линии

Изменения в таблице применяются немедленно.

Сохранение настроек обработки

Настройки обработки сигналов сохраняются в файл настроек каналов (*_channelSettings.stn) вместе с файлом данных. При следующей загрузке файла настройки восстанавливаются автоматически.
