События и стимулы

Управление событиями и стимулами является ключевой функцией программы для анализа электрофизиологических данных.

События

События представляют собой временные метки значимых моментов в сигнале (пики, спады, онсеты и др.).

Таблица событий

Таблица событий отображается в нижней части боковой панели Signal Viewer. Содержит колонки:

  • Time - временная метка события
  • Comment - комментарий к событию

Ручное добавление событий

Простое добавление

  • Нажмите кнопку Add Event под таблицей событий
  • Или зажмите Ctrl и кликните мышью на графике в нужной точке

Событие добавляется в указанную точку времени.

Добавление с настройками

Меню Options/Manual events settings открывает окно настроек:

  • Detection Mode:
    • manual - событие добавляется в указанную точку
    • locked - событие корректируется к локальному экстремуму
  • Channel Number - номер канала для добавления события
  • Polarity - полярность поиска экстремума (positive/negative)
  • Time Window - временное окно поиска экстремума в миллисекундах (для режима locked)

В режиме locked программа ищет локальный экстремум (максимум или минимум в зависимости от полярности) в заданном временном окне и размещает событие в найденной точке.

Автоматическое обнаружение событий

Меню Analysis/Autodetection или кнопка Auto Event Detection открывает окно автоматического обнаружения.

Параметры детекции:

  • Detection Type:
    • one channel positive - обнаружение положительных пиков на одном канале
    • one channel negative - обнаружение отрицательных пиков на одном канале
    • two channels difference - обнаружение на основе разницы между двумя каналами
  • Minimal Peak Amplitude - минимальная амплитуда пика
  • Positive Channel / Negative Channel - каналы для режима two channels
  • Minimal Time Between Peaks - минимальное время между пиками
  • Smooth Coefficient - коэффициент сглаживания сигнала
  • Detection Mode - peaks (пики) или onsets (онсеты)

Использование:

  1. Настройте параметры детекции
  2. Нажмите Check Detection для предварительного просмотра
  3. Нажмите Apply для применения и добавления событий в таблицу

Редактирование событий

Меню Options/Edit events открывает окно редактирования событий. Позволяет:

  • Изменять временные метки событий
  • Изменять комментарии событий
  • Удалять события

Удаление событий

  • Выберите событие в таблице (введите номер в поле под таблицей)
  • Нажмите кнопку Delete Event

Кнопка Clear Table удаляет все события из таблицы.

Импорт событий из стимулов

Меню Options/Import events from stimulus создает события на основе временных меток стимулов.

Сохранение и загрузка событий

События сохраняются автоматически при сохранении ZAV файла. Для отдельного сохранения используйте кнопку Save Events под таблицей событий.

События загружаются при открытии EV файла или ZAV файла с сохраненными событиями.

Стимулы

Стимулы представляют собой временные метки подачи стимулов в эксперименте.

Таблица стимулов

Стимулы отображаются в средней части боковой панели Signal Viewer. Список показывает временные метки стимулов.

Редактирование стимулов

Кнопка Edit рядом с заголовком “Stimuli” или меню Options/Edit stimulus times открывает окно редактирования временных меток стимулов.

Скрытие стимулов

Меню View/Hide stimulus скрывает или показывает отображение стимулов на графике.

Автоматическое обнаружение стимулов

Модуль autoDetectStimuli может автоматически обнаруживать стимулы в сигнале. Используется через File Manager.

Загрузка стимулов из настроек

Стимулы могут быть загружены из файла настроек каналов (*_channelSettings.stn) при открытии файла, если флаг stims_loaded_from_settings установлен.

Средний трейс по событиям

Меню Options/Mean Events открывает окно настройки усреднения сигнала вокруг событий.

Параметры:

  • Time Window - временное окно вокруг события
  • Remove Baseline - вычитание базовой линии
  • Remove Artifact - удаление артефакта
  • Artifact Window - размер окна артефакта
  • Show Original Traces - показывать исходные трейсы
  • Auto Scale - автоматическое масштабирование

Кнопка Calculate строит график усредненного сигнала.

Средний трейс по стимулам

Аналогично событиям, можно построить средний трейс по стимулам. Используется модуль autoMeanStimulus через File Manager или аналогичные настройки в окне Mean Events при выборе стимулов как источника.

Навигация по событиям и стимулам

В Signal Viewer и Signal Analysis доступна навигация по событиям и стимулам:

  • Выберите режим event или stimulus в выпадающем списке режима просмотра
  • Кнопки Previous и Next перемещают отображаемый интервал к предыдущему/следующему событию или стимулу
  • Слайдер времени также работает в режиме навигации по событиям/стимулам

Визуализация событий и стимулов

События и стимулы отображаются на графике в виде вертикальных линий. Цвет и стиль линий настраиваются через меню View/Lines and styles.

Метаданные событий

При автоматическом обнаружении событий сохраняются метаданные:

  • Amplitude - амплитуда события
  • Channel - канал события
  • Width - ширина пика
  • Prominence - выраженность пика

Метаданные доступны через таблицу событий и используются в анализе.
