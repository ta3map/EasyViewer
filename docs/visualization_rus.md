# Визуализация

Программа предоставляет различные инструменты для настройки отображения сигналов и результатов анализа.

## Настройки отображения каналов

### Таблица каналов

Боковая панель Signal Viewer содержит таблицу настроек каналов:

- **Channel** - название канала
- **Enabled** - включение/выключение отображения канала
- **Scale** - коэффициент масштабирования амплитуды
- **Color** - цвет линии сигнала
- **Line Width** - толщина линии
- **Averaging** - участие в усреднении
- **CSD** - участие в CSD
- **Filter** - применение фильтрации
- **Baseline** - вычитание базовой линии

![Таблица каналов](images/placeholder_channel_table.png)

### Быстрое управление

Кнопки под таблицей каналов:

- **(De)select ch** - переключение видимости всех каналов
- **(De)select CSD** - переключение участия всех каналов в CSD
- **(De)select Baseline** - переключение вычитания базовой линии

### Вертикальное смещение

Поле **Ch. Shift** определяет величину вертикального смещения между каналами в единицах амплитуды сигнала. Увеличение значения увеличивает расстояние между каналами на графике.

## Цвета и стили линий

### Настройка цветов каналов

Цвет каждого канала настраивается в таблице каналов. Доступны стандартные цвета MATLAB (r, g, b, k, m, c, y) или RGB значения.

### Стили линий событий и стимулов

Меню **View/Lines and styles** открывает окно настройки стилей линий для событий и стимулов.

**Параметры для каждого типа линий:**

- **Line Color** - цвет линии
- **Line Style** - стиль линии (-, --, :, -.)
- **Line Width** - толщина линии
- **Label Text** - текст метки
- **Label Color** - цвет метки
- **Label Font Size** - размер шрифта метки
- **Label Background Color** - цвет фона метки
- **Label Font Weight** - начертание шрифта (normal/bold)

![Настройки стилей линий](images/placeholder_lines_styles.png)

## Zoom и Pan

### Built-in Zoom

Меню **View/Built-in Zoom** или кнопка **Zoom** активирует встроенный инструмент зума.

**Использование:**

1. Активируйте Zoom
2. Выделите область на графике для увеличения
3. Кликните правой кнопкой мыши для уменьшения

![Zoom инструмент](images/placeholder_zoom.png)

### Built-in Pan

Меню **View/Built-in Pan** или кнопка **Pan** активирует встроенный инструмент панорамирования.

**Использование:**

1. Активируйте Pan
2. Зажмите левую кнопку мыши и перемещайте график
3. Отпустите кнопку для завершения

![Pan инструмент](images/placeholder_pan.png)

### Home

Кнопка **Home** сбрасывает все инструменты (Zoom, Pan, Cursor) и восстанавливает исходный вид графика с автоматическим масштабированием.

## Data Cursor

Меню **View/Data Cursor** или кнопка **Cursor** активирует курсор данных.

**Использование:**

1. Активируйте Data Cursor
2. Кликните на графике в интересующей точке
3. Отображаются координаты точки (время, амплитуда, канал)

![Data Cursor](images/placeholder_data_cursor.png)

## Brush

Кнопка **Brush** активирует инструмент выделения данных на графике. Позволяет выделять точки данных для дальнейшего анализа.

![Brush инструмент](images/placeholder_brush.png)

## Сохранение графиков

### Сохранение снимка графика

Меню **File/Save figure snapshot** в Signal Viewer сохраняет текущий график в файл изображения.

**Форматы:**

- PNG
- FIG (MATLAB figure)
- PDF
- EPS

![Сохранение графика](images/placeholder_save_figure.png)

### Сохранение изображения в Signal Analysis

Кнопка **Save Image** в Signal Analysis сохраняет текущий график анализа.

## Настройки осей

### Единицы измерения времени

Выпадающий список единиц измерения позволяет выбрать:

- **s** - секунды
- **ms** - миллисекунды
- **min** - минуты

Выбранная единица применяется ко всем временным параметрам и отображению на оси времени.

### Автоматическое масштабирование

Графики автоматически масштабируются для оптимального отображения данных. При использовании Zoom/Pan масштабирование может быть изменено вручную.

### Восстановление масштаба

Кнопка **Home** восстанавливает автоматическое масштабирование и исходный вид графика.

## Скрытие элементов интерфейса

### Скрытие боковой панели

Кнопка **×** в верхней части боковой панели или меню **View/Hide Channel Settings** скрывает боковую панель для увеличения области графика.

Кнопка **□** или меню **View/show Channel Settings** восстанавливает панель.

### Скрытие стимулов

Меню **View/Hide stimulus** скрывает или показывает отображение стимулов на графике.

## Отображение CSD и MUA

### CSD

Чекбокс **CSD** на панели инструментов включает отображение Current Source Density. Настройки CSD доступны через меню **View/CSD displaying**.

### MUA

Чекбокс **MUA** включает отображение мультиюнитной активности. Поле **MUA coef** задает порог отображения в единицах стандартного отклонения.

## Настройки графика в Signal Analysis

В Signal Analysis доступны дополнительные настройки:

- Отображение элементов измерения (baseline, peak, slope, onset)
- Переключение между исходным и сглаженным сигналом
- Отображение среднего трейса

Все настройки применяются немедленно к графику.

## Экспорт графиков

Графики могут быть экспортированы в различные форматы:

- **PNG** - растровое изображение
- **FIG** - MATLAB figure файл
- **PDF** - векторный формат
- **EPS** - векторный формат для публикаций

Разрешение для растровых форматов: 300 DPI.
