Quick Start Guide

This guide will help you get started with Easy Viewer quickly.

Opening Files

ZAV Format Files

To open a ZAV format file: 1. Click File → open ZAV(.mat) file 2. Select your .mat file 3. The signal will be displayed automatically

Event Files

To load events: 1. Click File → open event (.ev) file 2. Select your .ev file 3. Events will be loaded and displayed in the events table

Basic Navigation

Time Navigation

  • Use the time slider to navigate through the signal
  • Click Previous and Next buttons to move by time window
  • Use arrow keys (← →) for quick navigation

Zoom

  1. Click the Zoom button
  2. Click two points on the graph to define zoom area
  3. Click Reset Zoom to return to full view

Channel Settings

Enable/Disable Channels

  • Use the channel table to enable or disable specific channels
  • Click the checkbox in the Enabled column

Adjust Scaling

  • Modify the Scale value in the channel table
  • Higher values increase signal amplitude

Change Colors

  • Edit the Color field in the channel table
  • Use MATLAB color codes (e.g., ‘r’ for red, ‘b’ for blue)

Event Management

Adding Events

  • Press Shift and click on the graph to add an event
  • Or use Add Event button

Deleting Events

  • Enter event number in the delete field
  • Click Delete Event button
  • Or press Delete key

Saving Events

  • Click Save Events button
  • Events will be saved with metadata

Analysis Tools

Auto Event Detection

  1. Click Analysis → Auto Event Detection
  2. Configure detection parameters
  3. Click Detect to find events automatically

Mean Events

  1. Load events or stimuli
  2. Click Mean Events button
  3. Average trace will be calculated and displayed

CSD (Current Source Density)

  1. Enable CSD in channel settings
  2. Click CSD checkbox
  3. CSD map will be displayed

Tips

  • Use File Manager to organize and search your files
  • Save channel settings for quick reuse
  • Export figures using File → save figure snapshot

Keyboard Shortcuts

  • ← / → : Navigate time
  • Delete : Delete selected event
  • Ctrl + Click : Add marker on graph
  • Shift + Click : Add event
