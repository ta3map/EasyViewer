# Модуль кластерного пермутационного теста

## Суть метода

Кластерный пермутационный тест (Cluster Permutation Test) — это статистический метод для анализа временных рядов нейрофизиологических данных, который позволяет определить, есть ли значимые изменения сигнала после стимула по сравнению с базовой линией (baseline).

**Основная идея:** метод сравнивает каждый момент времени после стимула с периодом до стимула, находит группы соседних значимых точек (кластеры) и проверяет их статистическую значимость через множественные перестановки данных.

**Зачем это нужно:** обычные статистические тесты при анализе временных рядов сталкиваются с проблемой множественных сравнений — чем больше временных точек проверяется, тем выше вероятность ложных срабатываний. Кластерный пермутационный тест решает эту проблему, корректируя статистическую значимость с учетом множественных сравнений и пространственной (временной) структуры данных.

## Как работает метод

### 1. Подготовка данных

Модуль извлекает данные вокруг каждого стимула (триал) в заданном временном окне. Окно включает период до стимула (baseline) и период после стимула. Для каждого триала вычисляется среднее значение baseline, которое используется как контрольная точка для сравнения.

**Обработка данных:**
- Удаление артефактов (опционально) — исключение короткого периода сразу после стимула
- Удаление baseline (опционально) — вычитание среднего значения baseline из каждого триала
- Циклическое дополнение — если триал выходит за границы записи, данные дополняются циклически (начало записи используется для конца окна и наоборот)

### 2. Вычисление t-статистики

Для каждой временной точки вычисляется парная t-статистика, которая показывает, насколько значение в этой точке отличается от baseline внутри каждого триала.

**Формула:** для каждого триала вычисляется разница между значением в точке времени и средним baseline этого триала. Затем по всем триалам вычисляется t-статистика как отношение среднего значения разниц к стандартной ошибке.

**Направление эффекта:** можно указать ожидаемую полярность эффекта (положительную или отрицательную), что определяет направление сравнения. Если ожидается положительный эффект, вычисляется (post-stimulus - baseline), если отрицательный — (baseline - post-stimulus).

### 3. Поиск кластеров

Кластеры — это группы соседних временных точек, где t-статистика превышает заданный порог значимости (например, |t| > 2.0, что соответствует p < 0.05 для двустороннего теста).

**Процесс:**
- Определяются все точки, где |t| > порог
- Соседние значимые точки объединяются в кластеры
- Для каждого кластера вычисляется сумма абсолютных значений t-статистик (или сумма квадратов) — это мера "силы" кластера
- Записывается момент начала кластера (onset) — первая временная точка кластера

### 4. Пермутационный тест

Для проверки статистической значимости кластеров выполняется множество пермутаций (перестановок) данных.

**Процесс пермутации:**
- Для каждой пермутации случайным образом меняются знаки разниц между точками времени и baseline для каждого триала (умножение на +1 или -1)
- Это разрывает связь между baseline и post-stimulus периодами, создавая "нулевую гипотезу"
- Для каждой пермутации снова вычисляются t-статистики, находятся кластеры и записывается максимальная статистика кластера

**Почему именно знаки:** для парного t-теста (сравнение внутри каждого триала) правильная нулевая гипотеза — это отсутствие систематического эффекта. Перестановка знаков разниц сохраняет структуру данных, но случайным образом меняет направление эффекта, что идеально подходит для проверки значимости.

### 5. Оценка значимости

После всех пермутаций формируется распределение максимальных статистик кластеров из пермутаций (null distribution).

**Критерий значимости:**
- Наблюдаемая статистика кластера сравнивается с этим распределением
- Если наблюдаемая статистика больше, чем в 95% пермутаций (или другом заданном проценте), кластер считается значимым (p < 0.05)
- P-значение вычисляется как доля пермутаций, где максимальная статистика была больше или равна наблюдаемой

**Коррекция множественных сравнений:** поскольку проверяется максимальная статистика из всех кластеров в каждой пермутации, метод автоматически корректирует на множественные сравнения. Это означает, что даже если проверяется тысячи временных точек, вероятность ложных срабатываний остается контролируемой.

## Параметры модуля

### Параметры визуализации

- **xLimits** — временное окно анализа в миллисекундах [до стимула, после стимула]. Например, [-500, 500] означает 500 мс до и 500 мс после стимула.
- **removeBaseline** — удалять ли среднее значение baseline из каждого триала перед анализом.
- **removeArtifact** — удалять ли артефакт стимула (короткий период сразу после стимула).
- **artifactWindow_ms** — длительность окна артефакта в миллисекундах.
- **showBaselinePeriod** — показывать ли baseline период на графике результатов.

### Параметры теста

- **numPermutations** — количество пермутаций для построения null distribution. Рекомендуется не менее 1000, для более точных результатов — 5000-10000.
- **clusterThreshold** — уровень значимости для определения порога t-статистики (обычно 0.05, что соответствует двустороннему тесту с |t| ≈ 2.0).
- **minClusterSize_ms** — минимальный размер кластера в миллисекундах. Кластеры меньшего размера игнорируются (по умолчанию 0 — все кластеры учитываются).
- **expectedPolarity** — ожидаемая полярность эффекта: "positive" (увеличение сигнала) или "negative" (уменьшение сигнала).

## Интерпретация результатов

### Визуализация

График показывает:
- **Синяя линия** — наблюдаемая t-статистика для каждой временной точки
- **Серая область** — доверительный интервал (процентили) из пермутаций (обычно 2.5% и 97.5%)
- **Зеленые области** — значимые кластеры (p < 0.05)
- **Красные маркеры** — моменты начала (onset) значимых кластеров с подписями времени в миллисекундах
- **Черная вертикальная линия** — момент стимула (t = 0)

### Метаданные

Результаты сохраняются в файл с расширением `.meta` и содержат:
- **t_observed** — матрица наблюдаемых t-статистик (временные точки × каналы)
- **clusters** — структура с информацией о кластерах для каждого канала (размер, статистика, p-значение, момент начала)
- **perm_percentiles** — процентили распределения пермутаций
- **cluster_onsets** — одномерный массив моментов начала всех значимых кластеров (в секундах)

### Ключевые показатели

- **Onset времени** — момент начала значимого эффекта после стимула. Это важный показатель для понимания временной динамики ответа.
- **Размер кластера** — длительность значимого эффекта. Большие кластеры указывают на устойчивый эффект.
- **P-значение** — вероятность того, что наблюдаемый эффект мог возникнуть случайно. P < 0.05 считается значимым.

## Преимущества метода

1. **Коррекция множественных сравнений** — автоматически учитывает проверку множества временных точек
2. **Учет временной структуры** — кластеры учитывают, что соседние точки времени коррелированы
3. **Непараметрический подход** — не требует предположений о распределении данных
4. **Применимость к парным данным** — правильно обрабатывает сравнение baseline и post-stimulus внутри каждого триала
5. **Визуальная интерпретация** — результаты легко интерпретировать визуально

## Ограничения

- Метод требует достаточного количества триалов (рекомендуется не менее 10-20)
- Вычисление пермутаций может занимать время при большом количестве временных точек и триалов
- Метод чувствителен к выбору порога кластеризации — слишком низкий порог может привести к ложным срабатываниям, слишком высокий — к пропуску реальных эффектов

## Применение

Модуль используется для:
- Определения наличия значимых изменений сигнала после стимула
- Оценки временной динамики эффекта (когда начинается, как долго длится)
- Сравнения эффектов между различными условиями эксперимента
- Валидации результатов других методов анализа
